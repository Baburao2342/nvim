# My Neovim dotfiles

Thanks to `kickstart.nvim` for a nice tutorial and guide, along with a great default config. I learnt some amazing vim motions and also have a great config now. 

Never really liked using my mouse. Now I can enjoy a good-enough neovim config with peace.

I use Lazy package manager here. Couldn't be bothered by the new vim.pack that has arrived in the market. I have shit to do instead of re-learning a new (and more verbose) package manager.

Theme is kanagawa. <3.

Clone my dotfiles:
```bash
git clone https://github.com/Natzukashi/nvim ~/.config/nvim
```

>[!warn]
>Remember to backup your existing configuration. Don't be a fool.

Neovim is the GOAT.
